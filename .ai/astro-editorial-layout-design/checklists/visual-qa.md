# 視覺驗收清單（四寬度 × 十二類檢查）

**`astro build` 通過只代表語法正確（失敗 F09）。** 交付前必須在 **1440／1280／768／390px** 四個寬度各看一次**整頁截圖**，再跑 `scripts/audit.mjs`。
截圖一律用整頁（fullPage），並**用眼睛看**：工具抓不到孤字、構圖失衡、圖像主體被裁、影像上文字可讀性。

```bash
# 1. 啟動
npm run build && npm run preview -- --port 4321
# 2. 量測（每頁 4 寬度截圖 + report.json；有 FAIL 則結束碼 1）
node scripts/audit.mjs --base http://localhost:4321 --paths /,/about --out ./audit-out
# 3. 看 audit-out/*.png（1440 與 390 必看；1280 與 768 看是否有「兩者之間才出現的問題」）
```
標記：**[A]** 腳本可量測；**[V]** 必須目視；**[M]** 手動操作（鍵盤、系統設定）。

## 0. 視窗規格

| 寬度 | 高度 | 代表 | 重點看 |
|---|---|---|---|
| 1440 | 900 | 桌機寬 | 容器是否過寬、留白是否過鬆、hero 是否在首屏完整 |
| 1280 | 900 | 筆電 | 與 1440 的差異：h1 vw 級距、gap 的 vw 部分 |
| 768 | 1024 | 平板直向 | **最容易壞**：兩欄剛好塌或未塌的斷點區間（760–900） |
| 390 | 844 | 手機 | 孤字、觸控、字級下限、頁面過長 |

另外建議補看 **1024** 與 **320**（`min-width:320px` 不得水平捲動）。

## 1. 溢出與裁切
- [A] `hScroll = 0`（四寬度皆是）
- [A] `spillCount = 0`（無元素超出視窗；被祖先 `overflow:hidden` 刻意裁切者不計）
- [V] 圖片、貼紙、印章、箭頭沒有被裁到只剩一半
- [V] `overflow:hidden` 的 hero 不切到標題字形
- [V] **背景色帶兩側是否露出底色**（F06）：1440 與 1280 看整頁左右緣

## 2. 留白
- [A] 水平 gutter：390 下內容左右各 ≥ 16px（`sections[].left`）
- [A] 章節間距（`gaps[]`）：同一頁 ≤ 3 種值；桌機 80–96px、手機 56–72px
- [V] 標題與內文之間 16–24px；內文與下一個標題之間 ≥ 32px
- [V] 沒有「滿版但貼邊」：文字距容器邊 ≥ 16px
- [V] 手機不出現連續 >120px 的空白區（常見於 `min-height` 殘留）

## 3. 對齊
- [V] 同一頁至多 3 條主要左對齊軸（容器左緣、內縮欄、縮排的第二行）
- [V] 同一列的卡片／欄位上緣對齊（`align-items:start`）；底部行動連結用 `margin-top:auto` 釘底
- [V] 欄與欄之間 gap ≥ 48px（桌機）；節點軸線穿過節點中心
- [V] 縮排（如 voice 行 `padding-left:.6em`）只在桌機使用；手機縮小或取消

## 4. 字級與斷行
- [A] `minFont ≥ 12px`；`smallText.lt12 = 0`（任何可讀文字）
- [A] 手機正文 ≥ 16px（中文 15px 為下限）；`body.approxCharsPerLine` 在 1440 為 24–40 全形字
- [A] `distinctFontSizes.length ≤ 12`（audit 以 0.5px 去重、含 clamp 計算值；設計時以 ≤ 9 個命名角色為目標）
- [A] h1：1440 ≥ 7vw（編輯式）；390 ≥ 40px；`h1.lines ≤ 4`
- [V] **每個標題末行 ≥ 2 字**（孤字，F12）— 四寬度都看
- [V] 標題換行在語意邊界（詞組不被拆開）
- [V] CJK 大標兩行字形不接觸（line-height ≥ 1.04、letter-spacing ≥ −.04em）

## 5. 色彩與對比
- [A] `contrastFail = 0`（文字 ≥ 4.5:1，大字 ≥ 3:1；腳本自動略過 `aria-hidden` 與背景圖上的文字）
- [V] **背景圖／漸層上的文字**（腳本略過）：取樣文字位置的背景色手算對比，遮罩處 ≥ 48% 不透明
- [V] 深色帶內的強調色已換成淺色（F：深帶沿用淺底強調色）
- [V] 只靠顏色表示的狀態（已完成、待填）另有文字或圖示

## 6. 圖片
- [A] 無 `object-fit:fill` 變形（`images[].distort`）
- [V] 主體在裁切後仍可辨識（390 的 cover 取中央，確認主體在中央）
- [V] 每張圖有 `alt`（裝飾 `aria-hidden`）；有 `width/height` 或 `aspect-ratio`（防 CLS）
- [V] 一頁只有一種媒體識別處理（R06）；傾斜 ≤ 3deg
- [V] 沒有未授權的人臉或第三方素材

## 7. 版面重排（手機）
- [V] 次要欄位被「隱藏」而不是縮到不可讀（如 ledger 類型標籤）
- [V] 分隔線方向跟著堆疊方向轉 90°（`border-left` → `border-top`）
- [V] 直排文字（writing-mode）保留時仍可點、可讀
- [V] header：logo／nav／CTA 不重疊、nav 可換行到第二列
- [V] 頁高：390px 整頁高度 ≤ 桌機 1440 頁高的 1.6 倍（十款：co 3090 vs 2375＝1.3；cg 3230 vs 2488＝1.3）

## 8. 互動
- [M] 全部互動元件可用 Tab 到達，順序 = 視覺順序；`:focus-visible` 可見（3px 外框）
- [M] `<details>` 用 Enter／Space 可開合；展開後內容不被裁切
- [M] 勾選／進度：無 JS 時內容仍可讀；有 JS 時 `aria-live` 更新
- [M] 表單：label 可見、錯誤訊息文字化

## 9. 觸控
- [A] 390／768：互動元素 ≥ 44×44（內嵌文字連結除外）；FAIL 閾值 <24px；WARN 閾值 <44px
- [V] 相鄰互動元素間距 ≥ 8px
- [V] 直排連結（writing-mode）的寬度也 ≥ 44px

## 10. Reduced motion
- [A] `reduced-motion` 下無限動畫數 = 0（audit 輸出 `reduced-motion`）
- [M] 系統開啟「減少動態效果」後，進場動畫、視差、呼吸動畫停止；內容不是 `opacity:0` 等 JS 才顯示
- [V] 每頁持續動畫 ≤ 1 個

## 11. 內容誠實與層級
- [V] 每個區塊標題是具體主張，不是「關於我們」「服務項目」
- [V] 沒有 Lorem ipsum、沒有編造的資格／見證／人數／日期／價格；佔位內容在畫面上**可見地標示**
- [V] 助人類：有「適合／不適合」與緊急資源欄位
- [V] 首屏回答「這是誰、做什麼、下一步是什麼」

## 12. 差異性
- [V] 依 `diversity-check.md` 填 8 旋鈕，與最近 2 款差異 ≥ 3 項
- [V] 沒有 ≥ 3 組同結構三欄卡片（F01）；Hero 不是「左文右圖＋兩按鈕」制式（F02）
