# 跨網站規律：共同遵守 vs 刻意不同

每條規律標註支持它的案例數（N/10）與證據標記。**「共同遵守」不等於「值得照抄」**——最後一節列出十款共同犯的缺陷。

## C. 十款共同犯的缺陷（不應重複套用）

這些是在 [MEAS] 中十款**全部**出現的問題，所以不能因為「十款都這樣」而當成規範：

| # | 缺陷 | 數據 |
|---|---|---|
| C1 | 大量 <12px 文字（mono 標籤 .5–.7rem） | 每頁 19–37 處；最小 7.7–9.6px |
| C2 | 手機觸控目標 <24px／<44px | 每頁 4–11／7–13 個 |
| C3 | CJK 標題 `letter-spacing ≤ −.08em` 搭配 `line-height ≤ .93` 使字形接觸 | es、ma、so、fn、cu、ll 6 款 |
| C4 | 手動 `<br/>` 在窄寬度產生孤字／怪斷行 | fn 390「解。」、cl 390「麼。」、es 1440 h2「案？」 |
| C5 | 裝飾性絕對定位元素（貼紙、印章、花、箭頭、直排字）隨視窗漂移，與文字重疊 | cu、co、so、ma、cg、es |
| C6 | 低對比小字（強調色疊在深色面板） | so kicker ≈1.4:1；cg `.cg-person-no` 3.97；es `.es-label` 4.48 |
| C7 | 字級種類過多（12–19 種） | co 19、ma 18–19、cg 18–19 |
| C8 | 內容全是示意文案，沒有真實層級（標題／摘要／日期／作者）的資料來源 | 10/10（原型性質） |
| C9 | 十頁互相導向 `/directions/`，無站內真實導覽 | 10/10（原型性質） |

## D. 區分表（寫給實作者）

- **可重用的設計原則**：A1–A3、A6（換聲標題）、A8–A12、A14、A16–A17，與 B 欄的「旋鈕」。
- **不應重複套用的風格特徵**：任何單款的識別組合 —— 拱形圖＋苔綠(fn)、硬陰影＋螢光底(ll)、白框旋轉靜物＋印章(cu)、波形帶(ra)、虛線摺痕＋郵戳(co)、遮罩影像 hero＋呼吸動畫(so)、階梯卡片＋橘影(ma)、貼紙＋薑黃圓(cg)。
  **這些是「那個人格」的簽名，拿來給另一個客戶就是換色模板。**
- **不可沿用的缺陷**：C1–C7。

## E. 可抽出的「構圖旋鈕」[NEW]

設計新站時，**不要選一款來改**；而是對下面每個旋鈕各選一個值，組合要與十款每一款至少在 3 個旋鈕上不同：

1. 主視覺關係：並排 / 疊壓(錯位) / 全幅 / 無圖(以字或圖表為視覺) / 圖表化(路線、日曆)
2. 閱讀軸：單欄 / 雙欄不對稱 / 三欄(邊注) / 固定側欄+彈性欄 / 水平帶狀
3. 標題聲音：大襯線書卷 / 粗無襯線海報 / 混聲 / 等寬編目
4. 結構線語彙：粗細線 / 面板底色 / 色帶 / 虛線 / 無線(只靠留白)
5. 列表隱喻：ledger / 軸線 / 目錄 / 日曆 / 地圖 / 時間表
6. 明度結構：全淺 / 全深 / 淺-深-淺 / 淺中嵌深面板
7. 互動主任務：閱讀 / 選擇 / 勾選 / 試聽 / 展開 / 無
8. 溫度：h1 行高(0.9–1.1)、正文行高(1.7–2.1)、圓角(0–50%)
