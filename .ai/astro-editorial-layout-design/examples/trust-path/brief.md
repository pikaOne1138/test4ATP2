# Brief — 信任路徑（工作流程步驟 1）

> 驗證用虛構站長。**資格、費用、時段、緊急資源全部為「待填」欄位**，頁面以旗標可見地標示，不編造任何真實資訊。

| 欄位 | 內容 |
|---|---|
| 站長是誰 | 一位獨立工作的生涯／工作諮詢者（虛構） |
| 訪客第一個問題 | 「我要怎麼知道這個人適不適合我？按下聯絡之後會發生什麼？」 |
| 要被怎樣信任 | **事先把路寫清楚**：範圍、方法、費用與時間、第一次見面的 50 分鐘、不適合時的去處 |
| 唯一主動作 | 先問一個一般問題（不需先決定要不要繼續） |
| 誠實限制 | 資格、費用、時段、緊急資源皆待站長填入；不放見證、不放人數、不放療效說法 |
| 語氣 | 平實、事先說明、不催促 ／ **不要**「立即預約」「限時」「名額有限」 |

## 內容層級表

| 區塊 | 主張（標題） | 證據 | 下一步 |
|---|---|---|---|
| Hero | 走近之前，先把路看清楚。 | 五站路線帶：範圍／方法／費用與時間／第一次見面／若不適合 | 先問一個一般問題 |
| 01 範圍 | 我能談的，和我不談的。 | 兩份清單＋緊急資源欄（待填） | 看方法 |
| 02 方法 | 三個動作，每個你只需要做一件事。 | 三步，各附「你只需要…」 | 看費用與時間 |
| 03 費用與時間 | 這些資訊會在你聯絡之前就寫好。 | 資訊表，每列有「已填／待填」旗標 | 看第一次見面 |
| 04 第一次見面 | 50 分鐘，這樣分配。 | 比例時間尺＋四段說明 | 若不適合 |
| 05 若不適合 | 不適合也是一個好結果。 | 轉介原則＋資源欄（待填） | 先問一個一般問題 |

## 與誠實相關的設計決定
- 「待填」是版面的一部分：旗標用 mono 小標＋品牌強調色，使佔位資料永遠看得見。
- 第一次見面的時間分配是**示意**（標「示意」），但結構（先界線、再傾聽、再整理、再決定）是設計主張。
