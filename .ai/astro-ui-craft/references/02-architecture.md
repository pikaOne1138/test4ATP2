# Architecture

## Knowledge / Blog
Primary job: help readers understand what the author knows, find a starting point, explore topics, and subscribe/read more.

Recommended homepage:
Hero → Start Here/topics → featured/latest → short About → optional resource → newsletter → Footer.

## Helper / Professional
Primary job: reduce uncertainty, build trust, explain fit/process, and make contact low-pressure.

Recommended homepage:
Hero → empathy → services → first-visit/process → About/credentials → trust/principles → FAQ → booking/contact → Footer.

The two architectures share primitives but not identical information architecture.
