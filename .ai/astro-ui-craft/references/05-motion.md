# Motion

Target: users may not explicitly notice animation, but the site feels cared for.

Defaults:
- hover: 150–220ms
- UI transition: 180–350ms
- reveal: 400–650ms
- movement: 4–16px
- scale: 0.98–1.03
- consistent ease-out curve

Good:
underline draw, arrow shift, subtle card/image lift, navbar blur transition, small fade-up/stagger, reading progress, FAQ accordion.

Prefer transform + opacity. Always support prefers-reduced-motion.
