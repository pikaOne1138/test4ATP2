# Design Principles

Refined UI is consistency, hierarchy and restraint—not extra effects.

- Use a stable spacing scale.
- Limit long-form measure to roughly 60–72ch.
- Use one main accent and a small neutral system.
- Keep image crop/radius/tone consistent.
- Prefer fine rules and whitespace before shadows.
- Every hover/click/load interaction should have small feedback.
- Avoid generic AI/SaaS visual defaults.
- A visitor should understand the page job before noticing decoration.
