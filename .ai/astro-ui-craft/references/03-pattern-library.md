# Pattern Library

## Navigation
Default desktop: Logo + 4–5 text links + one right-side CTA.
- Knowledge CTA: Subscribe.
- Helper CTA: Book/Contact.
- Sticky header is useful; blur/solid transition is optional.
- Avoid mega menus in beginner templates.

## Homepage
Keep roughly 6–8 meaningful sections.
Do not turn every section into three icon cards.

## Helper trust patterns
- clear first-visit/process section;
- service fit + boundaries;
- credentials near About;
- FAQ before booking;
- Taiwan-friendly LINE/contact path when relevant.

## Knowledge patterns
- Start Here;
- topic taxonomy;
- featured + latest content;
- consistent newsletter CTA;
- readable article layout.
