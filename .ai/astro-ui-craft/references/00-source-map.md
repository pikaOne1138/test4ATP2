# Source Map

## Evidence levels
1. Direct page/screenshot/computed-CSS observation.
2. Web-searched and page-verified observation.
3. Cross-case pattern analysis from verified cases.
4. Synthesized design proposal / tokens.
5. Memory-only or explicitly unverified candidate.

## Raw research
See `raw-research/`.

High-signal sources:
- Arena: complete case pools, Top 10, navigation/homepage patterns, CSS/motion/CTA/article patterns, final briefs.
- Claude visual research: some cases include screenshot + computed CSS verification.
- Claude 3-style spec: Paper & Ink / Morning Light / Quiet Studio design system proposal.
- Gemini / Grok / Mistral / Perplexity / Tenbin runs: candidate expansion and independent synthesis.

`gpt-work-AstroTmplateResearch.html.html` is retained outside GitHub in the original research archive because the export embeds very large base64 screenshots. Its conclusions should be re-verified before use.
