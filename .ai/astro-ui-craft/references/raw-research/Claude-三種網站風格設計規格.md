# Astro 架站工作坊｜三種網站風格設計規格

Oct 8, 2026 · @pikaOne

## 總覽

三種風格共用同一套 Astro 骨架與元件，只換「設計 tokens（顏色、字體、圓角、陰影、動畫曲線）」就能切換氣質。每種風格都有 A 知識型、B 助人者型兩個版本，學員選風格後，再選 A 或 B。

| 風格 | 一句話氣質 | 最適合 A（知識型） | 最適合 B（助人者型） | 關鍵視覺記憶點 |
| --- | --- | --- | --- | --- |
| 一｜紙墨 Paper & Ink | 像一本排版講究的獨立雜誌 | 長文寫作者、評論、讀書筆記、專業專欄 | 顧問、教練、有論述的心理師 | 襯線大標、細線分隔、紙張米白底 |
| 二｜晨光 Morning Light | 像早上灑進窗戶的光，柔軟安全 | 生活感部落格、身心靈筆記、療癒系創作者 | 諮商師、催眠師、療癒師、身心靈工作者 | 大圓角、柔和漸層光暈、有機曲線 |
| 三｜靜室 Quiet Studio | 像一間安靜、乾淨的工作室 | 技術筆記、知識庫、專業文章 | 身體工作者、專業顧問、需要可信度的服務者 | 大量留白、精準格線、單一強調色 |

### 共用設計原則

**精緻感的定義（給學員的白話版）：** 不是「加很多效果」，而是「每個細節都有被照顧到」。具體做到這 6 件事，網站就會「感覺很精緻」：

1. 間距有規律：全站只用 4、8、12、16、24、32、48、64、96、128px 這組數字。
2. 文字行寬有限制：內文每行 60–72 個中文字寬以內（`max-width: 68ch`）。
3. 顏色少而準：1 個主色 + 1 個強調色 + 3 階灰。
4. 陰影很淡、會分層：不用黑色陰影，用帶主色調的半透明陰影。
5. 互動有回饋：滑過、點擊、載入都有 150–400ms 的輕微變化。
6. 圖片有統一處理：同比例、同圓角、同色調。

**微動畫三條鐵則：**

- 時間：hover 150–200ms；元素進場 400–600ms；頁面轉場 250–350ms。超過 700ms 就會被「看見」，失去精緻感。
- 距離：位移只用 4–16px；縮放只用 0.98–1.02。
- 曲線：統一用 `cubic-bezier(0.22, 1, 0.36, 1)`（ease-out-quint，快進慢停），不用預設 `ease`。

**無障礙底線（必做）：** 所有動畫包在 `@media (prefers-reduced-motion: no-preference)` 裡；文字對比度至少 4.5:1；按鈕觸控區至少 44×44px；`:focus-visible` 要有清楚外框。

**技術選擇（為了不會程式的學員）：** 純 CSS + Astro 內建 View Transitions；進場動畫用一支約 15 行的 IntersectionObserver 小腳本。不裝 Tailwind、不裝動畫套件，降低學員除錯成本。

## 風格一｜紙墨 Paper & Ink

### 核心風格

像一本獨立雜誌或文學刊物：米白紙張底、深墨色字、襯線大標題、細線分隔。內容本身就是主角，視覺只負責「讓文字好讀、讓人覺得作者很認真」。關鍵字：編輯感、沉穩、有觀點、耐讀。

### 目標使用者

- A：長文寫作者、書評與讀書筆記、產業評論、專欄作家、想累積 SEO 長尾流量的專業者。
- B：顧問、商業教練、有理論論述的心理師、講師，想用「文章建立權威」再轉成預約的人。

### Sitemap

| A 知識型 | B 助人者型 |
| --- | --- |
| 首頁 / | 首頁 / |
| 文章列表 /writing | 服務 /services（含各服務子頁） |
| 文章內頁 /writing/\[slug\] | 關於 /about |
| 分類／標籤 /topics/\[tag\] | 文章 /writing（觀點文章） |
| 關於 /about | 常見問題 /faq |
| 電子報 /newsletter | 預約 /contact |
| RSS /rss.xml、404 | 隱私權政策 /privacy、404 |

### Navbar

- 桌機：左側「文字型 Logo」（襯線字、字距 0.02em），右側 4 個連結 + 一個文字型 CTA（A：「訂閱」；B：「預約諮詢」，外框按鈕）。
- 高度 72px，底部 1px 細線（`--line`）。
- 捲動行為：往下捲時 Navbar 收起，往上捲時滑回（`translateY`，300ms）。捲動超過 80px 後，高度縮為 60px，背景加 `backdrop-filter: blur(8px)` 與 92% 不透明的紙色。
- 目前所在頁：連結下方 1px 底線，不用顏色區分。

### Homepage Sections

**A 知識型（由上到下）：**

1. 刊頭 Hero：一行大標（作者的寫作主張，例如「把讀過的東西，寫成想得通的東西」）+ 一句副標 + 訂閱輸入框。無主視覺圖，靠字撐場。
2. 精選文章：1 篇大卡（左文右圖）+ 2 篇小卡。
3. 最新文章：條列式清單（日期｜標題｜閱讀時間），像雜誌目錄。
4. 主題索引：5–8 個主題標籤，附各主題文章數。
5. 關於作者小框：頭像 + 3 行介紹 + 「更多關於我」。
6. 電子報 CTA 區塊。

**B 助人者型：**

1. Hero：大標寫「你幫誰解決什麼」（例如「陪經理人把難做的決定，想清楚」）+ 副標 + 主按鈕「預約初談」+ 次按鈕「看服務內容」。右側放一張黑白或低飽和人像。
2. 你是否也正在…：3–4 條痛點陳述，用編號 01、02、03 排版。
3. 服務項目：2–3 張服務卡（名稱、適合誰、形式、時長、價格區間）。
4. 工作方式：3 步驟（初談 → 對焦 → 陪伴）。
5. 觀點文章：最新 3 篇，建立專業信任。
6. 見證：1 則引言大字排版（襯線斜體引號），附姓名縮寫與身份。
7. 最終 CTA。

**不同裝置排版：**

| 區塊 | 桌機 ≥1024px | 平板 768–1023px | 手機 <768px |
| --- | --- | --- | --- |
| 容器寬 | 1120px，12 欄格線 | 左右 40px 邊距，8 欄 | 左右 20px 邊距，單欄 |
| Hero 大標 | 64px | 48px | 36px（`clamp()` 自動縮放） |
| 精選文章 | 大卡 7 欄 + 小卡 5 欄並排 | 大卡全寬、小卡兩欄 | 全部單欄堆疊 |
| B 的 Hero 人像 | 右側 5 欄 | 縮小置右 | 移到標題下方，4:5 比例 |

### Article layout

- 單欄置中，內文寬 `68ch`；標題區寬一點（`48rem`）。
- 標題區：分類（小字大寫字距）→ 大標（襯線 48px）→ 摘要（20px 灰字）→ 作者・日期・閱讀時間 → 細線。
- 內文：18px、行高 1.85；段落間距 1.4em；首段第一個字可做「首字放大」（drop cap，選用）。
- 引言：左側 2px 墨色直線 + 襯線斜體。
- 桌機 ≥1280px：右側浮動目錄（sticky），目前段落高亮；手機改成標題下方可展開的「本文目錄」。
- 頁面頂部 2px 閱讀進度條（墨色）。
- 文末：作者小卡 → 電子報 CTA（A）或預約 CTA（B）→ 相關文章 3 篇。

### About page

- 開頭像雜誌人物專訪：大標「我是誰，我在做什麼」+ 一張橫幅照片。
- 「我的故事」用 3 段短文 + 年份時間軸（左側年份、右側事件，細線串起）。
- B 版加：專業資歷（學歷、證照、受訓）列表、「我相信的事」3 條信念。
- 結尾：A 導向訂閱、B 導向預約。

### CTA

- 語氣克制、像邀請而非推銷。A：「每週一封，讀完會想一想的信」；B：「先聊 20 分鐘，看看我們合不合適」。
- 形式：滿版米色深一階的區塊，中央大標 + 一個按鈕；上下 96px 留白。

### Color palette

| Token | 色碼 | 用途 |
| --- | --- | --- |
| `--paper` | `#F7F4EE` | 背景（米白紙） |
| `--paper-2` | `#EFEAE0` | 區塊底色、CTA 底 |
| `--ink` | `#1F1D1A` | 主文字、主按鈕 |
| `--ink-2` | `#5C5850` | 次要文字 |
| `--line` | `#DDD6C8` | 分隔線、卡片邊框 |
| `--accent` | `#9A3B2E` | 強調色（朱砂紅）：連結底線、標籤、hover |
| 深色模式背景 | `#171614` | 文字改 `#ECE7DD` |

### Typography

- 標題：Noto Serif TC（思源宋體）600；英文搭 Fraunces 或 Source Serif 4。
- 內文：Noto Sans TC 400（中文長文用黑體較好讀）；也可整站用宋體增加文學感（給學員二選一）。
- 字級（`clamp` 響應式）：H1 36→64px、H2 28→40px、H3 22→26px、內文 17→18px、小字 14px。
- 細節：標題字距 0.01em、內文字距 0.02em；中英混排用 `text-autospace`（瀏覽器支援時）。

### Buttons

- 主按鈕：墨色實心、紙色字、圓角 2px、高 48px、左右 24px padding。
- 次按鈕：1px 墨色外框、透明底。
- 文字按鈕：文字 + 「→」，hover 時箭頭右移 4px。
- Hover：主按鈕背景變 `--accent`（200ms）；按下 `scale(0.98)`。

### Cards

- 文章卡：無陰影、無底色，用上方 1px 細線分隔；圖片 3:2；標題襯線 22px。
- Hover：標題加朱砂紅底線（由左往右畫出，`background-size` 0→100%，300ms）；圖片 `scale(1.03)`（600ms）。
- 服務卡（B）：1px `--line` 外框、圓角 4px、內距 32px；hover 邊框變墨色。

### Images

- 統一比例：文章封面 3:2，人像 4:5。
- 色調：低飽和或黑白；可在 CSS 加 `filter: saturate(0.85)` 統一。
- 圓角 2px（幾乎直角，保留刊物感）。
- 載入：Astro `<Image>` 自動轉 WebP + `loading="lazy"`；載入完成前顯示 `--paper-2` 色塊。

### Micro animations

| 動畫 | 做法 | 參數 |
| --- | --- | --- |
| 標題逐行浮現 | Hero 大標每行 `opacity 0→1` + `translateY 12px→0`，行與行間隔 80ms | 600ms |
| 連結底線畫出 | `background-image` 底線 `background-size: 0% 1px → 100% 1px` | 300ms |
| 段落進場 | 捲動到時淡入上移 8px | 500ms |
| 閱讀進度條 | 頁頂 2px，隨捲動比例伸長（CSS `animation-timeline: scroll()`，不支援時用小腳本） | 即時 |
| 頁面轉場 | Astro View Transitions：舊頁淡出、新頁淡入 + 上移 6px；文章卡標題以 `transition:name` 平滑變成內頁大標 | 300ms |
| 引言出現 | 左側直線由上往下長出（`scaleY 0→1`） | 500ms |

### Mobile behavior

- Navbar：Logo + 漢堡鈕（兩條細線，展開時轉成 ×，200ms）。
- 選單：全螢幕紙色覆蓋，連結襯線 32px，依序淡入（間隔 50ms）。
- B 版：手機底部固定一條 56px「預約諮詢」列，捲過 Hero 後才出現、捲到頁尾 CTA 時隱藏。
- 文章目錄改為可展開；表格可橫向捲動並有漸層提示。

### Footer

- 上方 1px 墨線；三欄：左為 Logo + 一句話介紹；中為站內連結；右為訂閱框（A）或聯絡資訊與社群（B）。
- 最底一行小字：版權、隱私權、RSS。
- 手機：三欄變單欄，訂閱框置頂。

### 元件（此風格特有）

- `<IssueHeader>`：刊頭式 Hero（大標 + 期號感的日期列）。
- `<ArticleIndex>`：目錄式文章清單。
- `<PullQuote>`：大字引言。
- `<Timeline>`：About 頁年份時間軸。
- `<NumberedList>`：01／02／03 痛點列表（B）。

  --font-heading: "Noto Serif TC", "Source Serif 4", serif;
  --font-body: "Noto Sans TC", system-ui, sans-serif;

  --shadow: none;

## 風格二｜晨光 Morning Light

### 核心風格

像早上灑進窗戶的光：暖奶油底、柔和的橘粉光暈、大圓角、有機曲線分隔。第一眼的感受是「這裡是安全的、被接住的」。關鍵字：溫柔、安心、有呼吸感、不壓迫。最適合需要降低訪客心理防備的助人者。

### 目標使用者

- A：療癒系部落格、身心靈學習筆記、生活與自我覺察寫作者、人類圖／占星／塔羅內容創作者。
- B：諮商師、心理師、催眠師、療癒師、能量工作者、生命教練。訪客常帶著焦慮或猶豫來，網站要先讓人放鬆，再引導預約。

### Sitemap

| A 知識型 | B 助人者型 |
| --- | --- |
| 首頁 / | 首頁 / |
| 文章 /journal | 認識我 /about |
| 文章內頁 /journal/\[slug\] | 服務 /services、各服務 /services/\[slug\] |
| 主題 /themes/\[tag\] | 第一次來？/first-visit（流程、費用、地點、注意事項） |
| 關於 /about | 心情文章 /journal |
| 資源 /resources（免費下載、推薦書單） | 常見問題 /faq |
| 電子報 /letters | 預約 /booking |
| 404 | 隱私權與保密說明 /privacy、404 |

> 「第一次來？」是助人者網站最重要的一頁：把未知變已知，焦慮就會下降。

### Navbar

- 桌機：浮動膠囊型 Navbar，距頂 16px、置中、最大寬 960px、圓角 999px、半透明奶油底 + `backdrop-filter: blur(12px)` + 極淡陰影。
- 左側 Logo（圓形小圖示 + 名字），中間連結，右側實心膠囊按鈕「預約」（A 為「訂閱來信」）。
- 捲動超過 40px 後陰影加深一階、背景不透明度從 70% 升到 88%。
- 目前頁面：連結背後出現一顆柔色膠囊底，切換頁面時用 View Transitions 讓膠囊「滑」到新連結。

### Homepage Sections

**A 知識型：**

1. Hero：左側大標（例如「慢慢讀，慢慢懂自己」）+ 副標 + 訂閱框；背景一顆緩慢飄移的柔光漸層球。
2. 這裡有什麼：3 張主題卡（圖示 + 主題名 + 一句說明）。
3. 最新文章：卡片格狀，2–3 欄。
4. 免費資源：一張大卡（例如「21 天覺察練習 PDF」）+ 下載按鈕。
5. 關於我：圓形頭像 + 溫暖的 3 行自我介紹。
6. 來信 CTA。

**B 助人者型：**

1. Hero：大標寫感受而非資歷（例如「你不用一個人撐著」）+ 副標寫你陪伴誰 + 主按鈕「預約第一次晤談」+ 次按鈕「第一次來？先看看」。右側一張自然光人像或空間照，圓角 32px 或拱門形遮罩。
2. 你可能正在經歷：4 張柔色小卡（失眠、關係卡住、情緒反覆、生命轉折…）。
3. 我可以怎麼陪你：2–3 項服務卡，含形式（線上／實體）、時長、費用。
4. 第一次晤談會發生什麼：4 步驟流程（預約 → 填寫簡短表單 → 初次晤談 → 一起決定下一步），用柔線串起。
5. 關於我：照片 + 一段第一人稱的話 + 專業背景摘要 + 「更認識我」。
6. 來訪者的話：2–3 則匿名見證輪播（若職業倫理不允許見證，改放「我的工作信念」）。
7. 常見問題精選 3 題（手風琴）。
8. 最終 CTA：柔光底的大區塊，「準備好了嗎？不急，你可以先看看」。

| Hero | 文字 6 欄 + 圖 6 欄 | 文字在上、圖在下（寬 80%） | 單欄，圖片縮為 4:3、圓角 24px |
| 痛點小卡 | 4 欄 | 2×2 | 橫向滑動卡片（scroll-snap） |
| 流程 4 步驟 | 橫向一排，連接線水平 | 2×2 | 垂直排列，連接線變垂直 |
| 區塊間距 | 128px | 96px | 72px |

### Article layout

- 內文寬 `66ch`，背景純奶油色；標題區上方有淡淡的漸層光暈。
- 標題區：主題膠囊標籤 → 大標 → 摘要 → 作者頭像 + 日期 + 閱讀時間。
- 封面圖：圓角 24px，寬於內文（突出內文寬度左右各 48px）。
- 內文：18px、行高 1.9（比一般更寬鬆，讀起來有呼吸）。
- 特殊區塊：「練習一下」提示框（柔綠底、左上葉子圖示）、「溫柔提醒」框（柔粉底）。
- 文末：「如果這篇文章觸動了你」CTA 卡（B 導向預約；A 導向訂閱）、相關文章 3 篇。
- B 版文末固定加一行安全提示：「若你正處於危機狀態，請撥打 1925 安心專線（24 小時）」。

### About page

- 開頭：大照片 + 第一人稱「嗨，我是…」。
- 段落：我為什麼開始做這件事 → 我的工作方式 → 我相信的事。
- B 版加：專業資格（證照字號、受訓背景、督導）用一個柔色卡片清楚列出，增加信任。
- 小彩蛋：「工作以外的我」3 張生活照，讓人感覺真實。

### CTA

- 語氣：給選擇、不催促。主 CTA「預約第一次晤談」，旁邊永遠附一個低門檻選項「先看看第一次來的流程」。
- 視覺：奶油底上的柔光漸層大圓角區塊（圓角 40px），按鈕為實心膠囊。

- 標題：Noto Serif TC 500（柔和襯線），英文搭 Fraunces（開啟 `SOFT` 軸更圓潤）。

- 細節：標題行高 1.3、字重不超過 600（太粗會顯得用力）。

### Buttons

- 主按鈕：陶土橘實心膠囊、白字、高 52px、左右 28px padding。

### Cards

- 白底（`#FFFDFA`）、圓角 24px、無邊框、極淡暖色陰影 `0 2px 12px rgb(58 51 48 / 0.06)`。

- 痛點卡：柔色底（蜜桃、霧粉、鼠尾草輪替），無陰影，只有圖示 + 一句話。

### Images

- 自然光、暖色調、生活感；避免冷調商業圖庫照。

## 風格三｜靜室 Quiet Studio

### 核心風格

像一間安靜、乾淨、光線剛好的工作室：近白灰底、大量留白、精準格線、單一深綠強調色、無襯線字體。給人的感受是「這個人很專業、很有條理、值得信任」。關鍵字：清晰、克制、專業、現代。適合需要建立可信度、又不想顯得冷冰的服務者，也適合結構化的知識庫。

### 目標使用者

- A：知識庫型網站（系列筆記、教學、方法論）、技術或專業領域寫作者、課程講師、想做「數位花園」的人。
- B：身體工作者（物理治療、整復、皮拉提斯、瑜伽）、專業顧問、職涯教練、營養師、有實體空間的工作室。

### Navbar

- 桌機：全寬、高 64px、白底；左 Logo（幾何小標誌 + 名字），中央連結，右側「搜尋鍵（⌘K）」（A）或深綠實心按鈕「預約」（B）。
- 捲動後底部出現 1px 灰線（一開始沒有，捲動後才淡入）。
- 連結 hover：底部 2px 深綠線從中間向兩側展開（`scaleX 0→1`，`transform-origin: center`）。
- B 版可加「服務」下拉選單：展開時淡入 + 下移 4px，內含服務名 + 一行說明。

### Homepage Sections

**A 知識型：**

1. Hero：左對齊大標（例如「把散落的知道，整理成可用的知識」）+ 副標 + 搜尋框。右側留白或一張極簡幾何圖。
2. 開始閱讀：3 個「新手入口」卡（從哪裡開始讀）。
3. 系列文章：橫向卡片，顯示每個系列的篇數與進度條。
4. 最新筆記：兩欄清單（標題 + 標籤 + 日期），密度高、易掃讀。
5. 標籤雲：膠囊標籤，依文章數由多到少排。
6. 現在 /now 摘要 + 訂閱。

**B 助人者型：**

1. Hero：分割版面，左 7 欄文字（大標 + 副標 + 「預約評估」+「看方案」），右 5 欄一張空間或工作中的照片。下方一列信任數字（例如「執業 8 年｜服務 1,200+ 人次｜國家證照」）。
2. 適合誰：3 欄圖示 + 短文（「久坐腰痛的上班族」「產後恢復」「運動傷害後」）。
3. 服務項目：服務卡格狀，每張有時長、形式、價格。
4. 方法：左側標題固定（sticky），右側 4 個步驟隨捲動依序出現。
5. 空間：3 張照片拼貼 + 地址與交通。
6. 見證或案例：卡片輪播，附前後對比的文字描述（不放身體照片以免倫理疑慮）。
7. 方案比較表：2–3 個方案並列，推薦方案以深綠框標示。
8. FAQ + 最終 CTA。

### Article layout

- 三欄式（桌機 ≥1280px）：左側「系列目錄」或標籤、中間內文 `70ch`、右側「本文目錄」sticky。
- 平板：隱藏左欄；手機：只留中間，目錄收進頂部可展開列。
- 標題區：麵包屑（筆記 › 系列名）→ 大標 → 更新日期（知識庫重視「最後更新」）→ 標籤。
- 內文：17px、行高 1.75；H2 前有 64px 空間 + 左側小編號（01、02）。
- 程式碼或步驟區塊：淺灰底、圓角 8px、右上角「複製」按鈕。
- 提示框：資訊（灰）、提醒（深綠）、注意（琥珀），左側 3px 色條。
- 系列文章：底部「上一篇／下一篇」大卡 + 系列進度（3 / 8）。

### About page

- 左右分割：左側大頭照 sticky，右側內容捲動。
- 內容：一段簡介 → 專業背景（表格式：年份｜經歷）→ 證照與受訓（小卡格狀，含發證單位）→ 工作原則 3 條。
- A 版加：「我用的工具」與「我正在學的東西」。
- B 版加：「與我合作的方式」與合作夥伴／轉介單位。

### CTA

- 語氣：清楚、具體、給資訊。「預約 30 分鐘評估｜NT$ 800｜線上或到府」。
- 視覺：深綠滿版區塊、白字，左側標題 + 說明，右側按鈕；或白底細框卡片。
- A 版：「訂閱更新」+「RSS」並列。

### Typography

- 全站無襯線：中文 Noto Sans TC；英文與數字 Inter 或 Geist（數字用 `font-variant-numeric: tabular-nums`，價格與數據對齊）。

- 層級靠「字重 + 灰階」而非大小差距；小標用 13px 大寫英文 + 0.08em 字距（例如 SERVICES）。

### Buttons

- 主按鈕：松針綠實心、白字、圓角 8px、高 44px。
- 次按鈕：白底 + 1px 邊框 + 深色字。
- Hover：背景加深 8%；按鈕右側箭頭從透明滑入（`opacity 0→1`、`translateX -4px→0`）。
- Focus：2px 綠色外框 + 2px 偏移，鍵盤操作清楚可見。

### Cards

- 白底、1px `--border`、圓角 12px、內距 24px、無陰影。
- Hover：邊框變 `--accent`、陰影 `0 1px 2px, 0 8px 24px`（極淡）、上移 2px。
- 進階精緻感：滑鼠在卡片上移動時，卡片背景有一顆極淡的跟隨光點（`radial-gradient` 跟著游標，透明度 6%）。一般人不會察覺，但會覺得「很高級」。

### Images

- 比例：服務 4:3、人像 1:1 或 4:5、空間照 16:9。
- 圓角 12px；照片風格明亮、乾淨、自然光、留白多。
- 圖片外加 1px 半透明內框（`outline: 1px solid rgb(0 0 0 / 0.06); outline-offset: -1px`），白底照片才不會「糊」進背景。

### 共用動畫核心（`motion.css`）

```css
@media (prefers-reduced-motion: no-preference) {
  [data-reveal] {
    opacity: 0;
    transform: translateY(12px);
    transition: opacity var(--dur-slow) var(--ease),
                transform var(--dur-slow) var(--ease);
    transition-delay: calc(var(--i, 0) * 80ms);
  }
  [data-reveal].is-in { opacity: 1; transform: none; }

  .btn { transition: transform var(--dur-fast) var(--ease),
                     background-color var(--dur-fast) var(--ease); }
  .btn:active { transform: scale(0.98); }
}
```

進場腳本（放在 `BaseLayout.astro` 底部）：

```html
<script>
  const io = new IntersectionObserver((entries) => {
    entries.forEach((e) => {
      if (e.isIntersecting) { e.target.classList.add('is-in'); io.unobserve(e.target); }
    });
  }, { rootMargin: '0px 0px -10% 0px' });
  const run = () => document.querySelectorAll('[data-reveal]').forEach((el) => io.observe(el));
  document.addEventListener('astro:page-load', run);
</script>
```

學員只要在想要「淡入」的元素加上 `data-reveal`，想錯落出現就加 `style="--i:1"`、`--i:2`，不用懂 JavaScript。

### 教學建議

1. 第一堂只讓學員改 `site.config.ts` 與寫第一篇 `.md`，當天就上線（Netlify 或 Vercel 拖曳部署），先建立成就感。
2. 第二堂示範「換 `tokens.css` = 換風格」，讓學員在三種風格間切換，再微調一個強調色。
3. 最後才碰元件順序：在首頁 `index.astro` 搬動、刪除區塊，理解「網站是積木」。
4. 風格選擇引導題：「你希望訪客第一眼覺得你：有深度（紙墨）／很溫暖（晨光）／很可靠（靜室）？」
