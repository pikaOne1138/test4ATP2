# 第二部分：Top 10 案例

## 知識／部落格 Top 10

### 1. Monograph

最適合研究「文字優先」的文章模板。重點不是首頁炫技，而是讓讀者快速進入文章，適合文章、筆記、技術教學與長期知識累積。

- 視覺：純文字、安靜、現代。
- 導航：極簡文字導航。
- Hero：通常不需要大型行銷式 Hero。
- 文章：標題、日期、分類、長文閱讀。
- 借鑑：內容優先、文章寬度、標題比例。
- 不適合初學者：太極簡時，品牌辨識度可能不足。

### 2. Patrika

適合「個人知識整理＋數位花園」的方向。它提供一種比一般 Blog 更有個性的內容隱喻：像田野筆記、手帳或長期研究檔案。

- 視覺：field notebook、自然、編輯感。
- 借鑑：分類不必做成傳統卡片，可以做成主題索引。
- Astro 實作：Content Collections、tags、related posts 很適合。

### 3. Method & Craft

適合研究高級 Editorial 版面。

- 視覺：設計雜誌、字體主導。
- 借鑑：大標題、微妙的格線、文本比例。
- 不建議直接照搬：複雜格線與藝術指導可能增加 CSS 難度。

### 4. Kinfolk

適合研究低彩度、攝影與大留白。

- 視覺：高級生活風格、沉靜、自然。
- 借鑑：圖片不需要大量裝飾，讓內容與攝影本身產生節奏。
- 不適合初學者：需要高品質攝影才能成立。

### 5. Cereal Magazine

適合研究雜誌首頁與文章封面。

- 視覺：極簡、旅行、建築、攝影。
- 借鑑：首頁可以使用少量大型內容區塊，不必每區三欄。
- Astro 難度：中，主要難在圖片比例與內容編排。

### 6. IEEE Spectrum

適合研究資訊量高、但仍然可閱讀的知識媒體。

- 視覺：專業、清楚、資訊密度高。
- 借鑑：分類、熱門文章、最新文章與搜尋。
- 適合：技術、AI、投資、研究型個人網站。

### 7. Biluo

適合研究現代 Astro Blog 應有的功能集合。

- 特色：Pagefind 搜尋、系列文章、標籤、RSS、sitemap、深色模式。
- 借鑑：功能完整但仍能保持靜態網站。
- 不建議第一版全部加入：搜尋與系列文章可以放入第二階段。

### 8. Framer Noter

適合作為初學者模板的內容方向參考。

- 視覺：作家、獨立創作者、電子報。
- 借鑑：文章列表、作者品牌、清楚的閱讀入口。
- Astro 難度：低～中。

### 9. Astro Nano

適合研究「最小可行 Blog」。

- 視覺：輕量、快速、低裝飾。
- 借鑑：首頁只放必要資訊。
- 很適合工作坊：學生容易理解元件與頁面結構。

### 10. Scholarly

適合研究知識工作者、研究者與專業人士的個人站。

- 視覺：可信、克制、學術但不老派。
- 借鑑：About、研究、出版、文章、履歷。
- 可轉用於：顧問、工程師、分析師、醫療或教育工作者。

## 助人者 Top 10

### 1. Myhra

最適合當作第一個助人者模板的基礎。

- Hero：先介紹「我是誰」與「我如何幫助你」。
- 首頁：個人背景 → 方法 → 服務 → 合作方式。
- 社會證明：資歷比大量客戶見證更自然。
- CTA：適合「了解合作方式」或「預約初談」。

### 2. Anza

適合一人專業服務者。

- 視覺：溫暖、個人、編輯感。
- 借鑑：把個人理念與服務結合。
- 適用：心理師、教練、顧問、身體工作者。

### 3. Jenani

適合整體健康與療癒服務。

- 視覺：安靜、留白、自然圖片。
- 借鑑：服務與預約入口清楚，但不過度銷售。
- CTA：預約、了解服務、聯絡。

### 4. Randi

適合作為課程中的「一頁式助人者網站」。

- 首頁結構：我幫助誰 → 我提供什麼 → 我是誰 → 如何開始。
- 優點：學生容易掌握。
- 缺點：複雜服務、長期內容與 SEO 不夠。

### 5. Clove

適合研究團體心理服務或多人專業團隊。

- 借鑑：團隊成員、專長、個別介紹。
- 可抽取到個人模板：專業資歷區塊與安全感語氣。

### 6. Therapi

適合研究「專業但不冰冷」。

- 視覺：暖中性色＋藍色。
- 借鑑：用色彩建立可信度，而不是只使用米色。
- 適合：心理師、諮商師、教練。

### 7. Everroot

適合研究低彩度自然風格。

- 視覺：灰白、淡色、照片帶來色彩。
- 借鑑：限制 UI 色彩，避免網站變成模板感。
- 不適合：需要強烈個人品牌或高轉換活動頁。

### 8. Bryce Ezrre

適合研究 Split Hero。

- 視覺：一側文字、一側圖片。
- 借鑑：首屏同時建立人物感與專業定位。
- Astro 難度：中。

### 9. Dené

適合研究成熟個人品牌。

- 視覺：詩意、Editorial、短文案。
- 借鑑：不把每一項服務都做成三欄卡片。
- 不適合初學者：需要很好的文案與影像素材。

### 10. Alexandria Art Therapy

適合研究高度個性化的助人服務。

- 視覺：藝術、療癒、個人品牌。
- 借鑑：服務方法可以透過圖片、作品與故事表達。
- 不建議：直接模仿複雜藝術展示效果。

# 第三部分：跨案例 Pattern Analysis

## 導航模式

### 知識／部落格常見模式

最常見且最實用的是：

```text
[Logo／網站名稱]
文章｜主題分類｜關於我｜資源
[搜尋] [訂閱電子報]
```

如果是單作者知識站：

```text
[OneOne／Site Name]
文章｜主題｜關於｜現在在研究什麼
                         [訂閱]
```

如果是雜誌或內容量較大的網站：

```text
[Logo]
最新｜主題分類｜熱門｜作者／關於
[搜尋] [電子報]
```

值得保留的功能：

- Sticky header。
- Scroll 後從透明變成實色或半透明背景。
- 右側搜尋按鈕。
- 右側電子報 CTA。
- 行動版漢堡選單。
- 長文章可使用閱讀進度條。
- 深色模式可以列為選配。

不建議第一版加入：

- Mega menu。
- 複雜多層分類。
- 行動版 bottom navigation。
- 太多 icon。
- 一開始就做站內即時搜尋。

### 助人者常見模式

```text
[Logo／姓名]
我能如何幫助你｜服務｜關於我｜文章／資源｜FAQ
                         [預約初談]
```

如果服務項目較少：

```text
[姓名／品牌]
關於我｜服務方式｜常見問題｜聯絡
                       [從這裡開始]
```

如果是心理師或諮商師：

```text
[Logo]
你可能正在經歷｜我提供的協助｜關於我｜文章｜FAQ
                              [預約初談]
```

助人者導航最重要的不是功能多，而是讓訪客知道：

1. 這個人是不是適合我。
2. 他／她能不能理解我的問題。
3. 服務怎麼進行。
4. 我下一步該做什麼。
5. 聯絡或預約是否安全、清楚、沒有壓力。

## 首頁排版

### 知識／部落格建議排序

```text
1. Header
2. 簡短 Hero／網站定位
3. 最新或精選文章
4. 主題分類
5. 長期內容／熱門文章
6. About 作者
7. 電子報
8. 社群或外部連結
9. Footer
```

更高級的做法是不要每區都使用三欄卡片，而是混合：

- 一篇大型精選文章。
- 兩至四篇較小文章。
- 一個文字型主題索引。
- 一個作者短介紹。
- 一個簡單電子報區塊。

容易變成罐頭網站的做法：

- Hero 大標題＋三個 icon。
- 三欄「快速、簡單、強大」。
- 每個主題都配一個圓形圖示。
- 大量不同圓角卡片。
- 所有 section 都使用同一個背景色。
- 每個 CTA 都寫「開始探索」。

### 助人者建議排序

```text
1. Header
2. Hero：你可能正在經歷什麼＋我能提供什麼
3. 我可以如何幫助你
4. 適合對象／可能適合你的情況
5. 方法與工作方式
6. 個人介紹
7. 專業資歷
8. 服務方案
9. FAQ
10. 預約／聯絡 CTA
11. Footer
```

推薦語可以放，但不一定要放在前面。對心理師、諮商師等專業而言，以下順序通常比「大標題＋五則見證」更自然：

```text
理解你的處境
→ 說明我的方法
→ 介紹我的背景
→ 告訴你合作如何進行
→ 提供低壓力的下一步
```

## CTA 分析

### 不建議助人者使用的 CTA

- 立即購買。
- 馬上改變人生。
- 搶位報名。
- 立刻成為更好的自己。
- 不要再拖延。
- 最後幾個名額。

這類語氣容易讓心理健康、療癒或脆弱狀態的訪客感到被推銷。

### 更適合的 CTA

| 層級 | CTA |
|---|---|
| Primary | 預約初談 |
| Primary | 了解合作方式 |
| Secondary | 看看這項服務是否適合你 |
| Secondary | 了解我的工作方法 |
| Low-pressure | 從這裡開始 |
| Low-pressure | 與我聊聊你的需求 |
| Low-pressure | 閱讀常見問題 |
| Low-pressure | 先看看文章與資源 |

### 知識／部落格 CTA

| 層級 | CTA |
|---|---|
| Primary | 訂閱電子報 |
| Primary | 閱讀最新文章 |
| Secondary | 探索主題 |
| Secondary | 閱讀精選文章 |
| Low-pressure | 查看所有文章 |
| Low-pressure | 了解作者 |
| Low-pressure | 加入 RSS |

# 第五部分：微動畫建議

| 動畫 | 適合位置 | 時間／Easing | 手機 | 效能 | 初學者模板 |
|---|---|---|---|---|---|
| Fade-up reveal | 首頁 section、文章卡片 | 500ms，`ease-out`，移動 16px | 適合 | 低 | 建議 |
| Stagger reveal | 文章列表、服務列表 | 每項延遲 40～70ms | 適合但少量 | 低 | 建議 |
| Image scale hover | 文章封面、服務圖片 | 450ms，scale `1.03` | Hover 無效 | 低 | 建議 |
| Underline animation | 文字連結、導航 | 250ms，`ease-out` | 適合 | 很低 | 建議 |
| Button arrow slide | CTA | 220ms，移動 4px | 適合 | 很低 | 建議 |
| Card lift | 卡片 | 250ms，translateY -3px | 可省略 | 低 | 可選 |
| Navbar blur | Sticky header | CSS backdrop blur | 適合但注意低階裝置 | 中 | 可選 |
| Scroll progress | 長文章 | 需少量 JS | 適合 | 低 | 第二階段 |
| Text highlight | Hero 或文章重點 | CSS background-position | 適合 | 很低 | 可選 |
| Smooth anchor | 目錄、區塊連結 | CSS `scroll-behavior` | 適合 | 很低 | 建議 |
| Gradient movement | 背景 | 6～12 秒循環 | 可停用 | 中 | 不建議第一版 |
| Reveal mask | 首圖、Hero | 700ms | 適合 | 中 | 可選 |
| Page transition | 頁面切換 | 300～500ms | 適合 | 中～高 | 第二階段 |
| Parallax | Hero 圖片 | 需 JS 或 scroll | 手機應停用 | 中 | 不建議第一版 |

所有 reveal 動畫都應加入：

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms;
    animation-iteration-count: 1;
    transition-duration: 0.01ms;
    scroll-behavior: auto;
  }
}
```

第一版 Astro 教學模板建議只放：

1. Fade-up。
2. Stagger。
3. Link underline。
4. Button arrow。
5. Image scale。
6. Sticky header。
7. Smooth anchor。

這些大多可用 CSS 完成，不會讓課程重點從「網站結構」偏移到 JavaScript 動畫。

# 文章頁研究結論

## 必備

- 最大閱讀寬度：`680px～760px`。
- 正文文字：桌面 `18px～20px`。
- 行距：`1.7～1.9`。
- 文章標題：桌面約 `48px～72px`，手機 `36px～46px`。
- 作者。
- 發布日期。
- 更新日期，若文章會持續維護。
- 分類與 Tag。
- 圖片與 `figcaption`。
- 文章內部連結。
- 回到文章列表。
- 基本 SEO metadata。
- 清楚的 mobile typography。

## 加分

- 閱讀時間。
- Sticky TOC。
- 閱讀進度條。
- Callout。
- 相關文章。
- 上一篇／下一篇。
- Newsletter CTA。
- 程式碼區塊與複製按鈕。
- 引用區塊。
- 社群分享。
- Footnote。
- 系列文章導覽。

## 可以先不做

- 即時留言。
- 登入。
- 個人化推薦。
- 複雜全文搜尋。
- 多層級互動圖表。
- 動態評論。
- WebGL 閱讀背景。
- 複雜頁面轉場。

## 建議文章頁結構

```text
文章分類
文章標題
副標題／引言
作者・發布日期・更新日期・閱讀時間

文章正文
文章內 TOC
Callout／引用／圖片
Tag
作者簡介
Newsletter
相關文章
上一篇／下一篇
Footer
```

對 Astro 工作坊而言，最重要的是建立「Markdown 內容 → layout → metadata → related posts」的清楚概念，而不是一開始加入所有互動功能。

- Navbar 收進漢堡。
- 文章列表改為單欄。
- 移除 hover-only 效果。
- TOC 改為 accordion。
- 文字與行距優先。

# 如果只能各做一套模板

## 知識／部落格模板

最值得融合：

1. **Monograph**
   - 取文字優先。
   - 取長文排版。
   - 取簡潔導航。

2. **Patrika**
   - 取數位花園與主題索引。
   - 讓網站具有「持續累積」的概念。

3. **Method & Craft**
   - 取 Editorial 字體比例。
   - 取大留白和編輯式標題。
   - 不照搬複雜格線。

4. **Kinfolk**
   - 取攝影、低彩度與留白。
   - 不依賴大量 UI 裝飾。

5. **Biluo**
   - 取 Astro 實作上的搜尋、標籤、系列文章與 RSS。
   - 初版可以只做文章、分類與 RSS，搜尋放第二階段。

最終應該做成：

```text
Editorial 視覺
＋
極簡長文閱讀
＋
數位花園式主題分類
＋
Astro 原生內容集合
```

## 助人者模板

最值得融合：

1. **Myhra**
   - 個人介紹與專業服務的平衡。
   - 先建立人與信任，再介紹服務。

2. **Anza**
   - 服務者的理念與方法。
   - 適合心理師、教練、顧問等個人專業者。

3. **Jenani**
   - 留白、自然圖片與低壓力預約入口。

4. **Clove**
   - 專業資歷、團隊或服務流程。
   - 可簡化成個人網站的 credentials section。

5. **Therapi**
   - 專業、不冰冷的色彩系統。
   - 避免網站看起來過度靈性或過度醫療化。

最終應該做成：

```text
溫暖 Editorial
＋
清楚服務架構
＋
個人背景與方法
＋
低壓力 CTA
＋
安全、易讀、可信的手機版體驗
```

最重要的收斂原則是：不要把兩種網站都做成「Hero＋三欄卡片＋Testimonials＋CTA」的 AI 生成式結構。知識網站應該以**內容探索與閱讀**為核心；助人者網站則應該以**理解、信任與安全地開始對話**為核心。
