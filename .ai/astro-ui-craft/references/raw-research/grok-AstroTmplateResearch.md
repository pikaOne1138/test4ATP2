# Astro 教學模板視覺研究與案例拆解

# you asked

我正在設計一堂給完全不會程式、也沒有網站開發背景者的 Astro 架站工作坊。
目前我只聚焦兩種網站模板：
A. 知識／部落格型網站
適合：
* 個人知識整理
* 部落格
* 個人觀點分享
* 專業文章
* 創作者內容基地
* 長期內容累積與 SEO
B. 助人者／個人專業服務網站
適合：
* 心理師
* 諮商師
* 催眠師
* 療癒師
* 身心靈工作者
* 身體工作者
* 教練
* 顧問
* 個人專業服務者
我的目標不是現在直接生成網站，而是先進行「大量視覺研究與模板拆解」。
請你上網搜尋中英文網站、模板平台、設計作品平台、開源網站與實際營運中的網站，幫我各找出：
* 知識／部落格型：至少 15～20 個高品質案例
* 助人者／個人專業服務型：至少 15～20 個高品質案例
搜尋來源請盡量廣，包括但不限於：
* Astro Themes

不要只找「技術上是 Astro」的網站。
我現在優先研究的是：
「哪些網站設計值得拿來做成 Astro 教學模板」。
也就是即使原網站是 Webflow、Framer、WordPress、Squarespace 或純客製網站，只要視覺、資訊架構與互動值得參考，都可以納入。

**第三部分：跨案例 Pattern Analysis**

**導航列常見模式**  
- Logo 左 + 主要連結中/右 + CTA 最右（最常見）。  
- Sticky header（scroll 後加背景/blur）。  
- Transparent → solid 切換。  
- 極簡文字導航（無 icon 堆疊）。  
- 漢堡選單（手機）。  
- CTA 按鈕右側（「訂閱」「預約初談」）。  
- 少見 mega menu（適合初學者避免）。  
- 深淺模式切換、搜尋按鈕（加分但非必須）。

**A. 知識／部落格最適合**  
`[Logo] 文章｜分類／主題｜關於｜資源  [訂閱電子報]`  
（或 `[Logo] 最新｜精選｜關於  [搜尋] [訂閱]`）

**B. 助人者最適合**  
`[Logo] 服務｜關於我｜資源／部落格｜FAQ  [預約初談／與我聊聊]`  
（手機：漢堡 + 底部固定 CTA 按鈕）

**首頁 Section 真實常見排序（非罐頭）**  
知識／部落格：Hero（個人/最新精選）→ 最新/精選文章網格 → 主題分類 → About 短介 → Newsletter → 熱門/資源 → Footer。  
高級感來自「文章優先、餘白大、少 icon 三欄」。避免每一區都 icon + 三欄。

助人者：Hero（溫暖人像 + 一句「我可以怎麼幫你」）→ 你是否正在經歷… → 服務項目 → 方法/理念 → 個人介紹 + 資歷 → Testimonials → FAQ → 預約 CTA → Footer。  
高級感來自「信任先行、低壓 CTA、真實照片」。避免過度銷售漏斗。

5. **Dark Intellectual**：bg `#121212` / text `#E8E6E3` / accent 金或紅。

【助人者】  
1. **Warm Therapeutic**：bg `#F9F6F1` / surface `#FFFFFF` / text `#2F2A26` / muted `#6B635B` / accent `#B07D62` / hover 加深。字體：Heading Playfair 或 Fraunces；Body Lora / Inter。Radius 12–16px；輕陰影。  
2. **Botanical Wellness**：綠系 accent + 自然圖片。  
3. **Calm Minimal**：米白 + 單一柔和 accent。  
4. **Editorial Professional**：類似知識型但加人像優先。  
5. **Spiritual but Modern**：柔和漸層背景（非霓虹）+ 乾淨字體。

優先 Google Fonts / 免費 Web Font（Inter、Source Serif、Noto、Playfair、Lora、Fraunces）。

**精緻感小動畫（優先純 CSS）**  
- Fade-up / stagger reveal：section 進入視窗，0.6–0.8s，ease-out，translateY 20–30px。適合手機，效能好，建議放入模板（加 `prefers-reduced-motion`）。  
- Image scale on hover：1.02–1.05，0.3s。  
- Underline animation：hover 時 width 0→100%。  
- Button arrow slide：0.2–0.3s。  
- Card lift：translateY -4px + 輕陰影。  
- Navbar blur / sticky：backdrop-filter。  
- Reading progress：頂部細線。  
- Smooth anchor。  
需 JS 的（parallax、page transition、reveal mask）標示為可選、進階，初學者模板先不做。全部尊重 reduced-motion。

**CTA 分析**  
助人者避免「立即購買／立即預約」硬銷。常見信任感用語：「預約初談」「了解這項服務是否適合你」「與我聊聊你的需求」「從這裡開始」「Book a consultation」。  
層級：  
- Primary：預約初談／與我聊聊。  
- Secondary：了解服務／閱讀更多。  
- Low-pressure：訂閱電子報／下載資源。  

知識／部落格：Primary 訂閱電子報；Secondary 閱讀文章；Low-pressure 關注社群。

**文章頁必備／加分／可先不做**  
必備：最大閱讀寬度 65–75ch、字級 18–20px、行距 1.6–1.8、標題比例清晰、發布日期、閱讀時間、Tag/Category、上一篇/下一篇、基本圖片 caption。  
加分：Sticky TOC、Reading progress、作者資訊、相關文章、引言/Callout、Quote、Newsletter CTA、分享按鈕。  
可先不做：Footnote 複雜系統、Code block 進階主題、動畫目錄。

**第四部分：兩套模板 Design Brief**

### 知識／部落格模板
1. 核心風格：Editorial warm minimal + Japanese 餘白感。

8. CTA：訂閱為主。

20. 最值得參考：The Marginalian、Austin Kleon、Zen Habits、Sumi 類、Japanese minimal。

### 助人者模板

2. 目標使用者：心理師、諮商師、教練、療癒師、顧問等。
