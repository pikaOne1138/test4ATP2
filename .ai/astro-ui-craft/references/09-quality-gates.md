# Quality Gates

Before handoff:
- Primary page job is obvious in 5 seconds.
- Navigation has one clear CTA.
- Homepage has no unnecessary sections.
- Theme differs in typography/geometry/motion, not only color.
- Desktop/tablet/mobile compositions are intentional.
- Focus/contrast/tap targets are usable.
- Motion remains subtle and optional.
- No accidental CRM/auth/database scope creep.
- Astro build succeeds.
